A one-image front page summing up Saturday 21 November 2026's world news:
Cyclone Akvan hitting India's east coast, the ICJ's genocide verdict on
Myanmar, the first-ever Trump–Xi–Putin trilateral in Shenzhen, Russia's
strikes on Kyiv's bridges, the GTA VI launch, and COP31's final stage —
plus a ticker strip with the day's other stories (EU's €8bn Ukraine payout,
the Houthi missile interception, the vendor cyber incident, Mongolia's
president resigning, and India's fightback in Wellington).

The image is drawn procedurally by `gen_image.py` (PIL) into `entry.png`
(1024×1024); `main.py` (standard library only) copies it to the output
directory, as the grading sandbox runs with no network.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
